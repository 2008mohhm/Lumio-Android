# Lumio

تطبيق Android Native عربي مبني بـ Kotlin وJetpack Compose لترجمة النصوص على الجهاز باستخدام ML Kit، مع سجل ومفضلة محفوظين عبر Room.

## ما يعمل فعليًا

- واجهة عربية RTL للوضعين الفاتح والداكن.
- اختيار لغات المصدر والهدف من اللغات المدعومة رسميًا في ML Kit.
- تنزيل نماذج الترجمات عند الحاجة، مع إشعارات حالة بالعربية.
- ترجمة نصية محلية على الجهاز بعد تنزيل النماذج.
- نسخة وترجمة التاريخ عبر Room، والمفضلة وحذف السجل.
- اختيار صور عبر Photo Picker مع OCR فعلي باستخدام ML Kit وفصل النصوص العربية واللاتينية.
- ترجمة ملفات TXT عبر SAF وإنشاء نسخة `.lumio.txt` عبر مجلد اختياري للمستخدم.
- إعدادات ثيم وخصوصية وإمكانية مسح البيانات المحلية.

## القيود المعروفة

- دعم Gemini، OCR المتقدم، PDF/DOCX/PPTX، والزر العائم غير منفذة في هذا الإصدار ولا تظهر كميزات قابلة للضغط.
- OCR يدعم اللاتينية والعربية حسب الموديل المثبت؛ جودة النتيجة تعتمد على جودة الصورة واللغة والجهاز.
- TXT مدعوم فقط حاليًا للملفات النصية UTF-8 أو الأنظمة الشائعة؛ بقية الامتدادات تظهر كغير مدعومة.
- لا يوجد أي مفتاح سحابي أو endpoint خارجي في التطبيق.

## بناء المشروع

يتطلب مشروع التطبيق:

- JDK 17
- Android SDK 35
- Gradle أو Android Studio إصدارًا حديثًا يدعم AGP 8.7

```bash
./gradlew testDebugUnitTest assembleDebug
```

إذا لم يكن Wrapper موجودًا بعد استنساخ المستودع، يمكن تشغيله من Android Studio لتوليد Wrapper ثم رفع نتائج التوليد.

## GitHub Actions

يسمح Workflow المرفق ببناء `app-debug.apk` ورفعه كـ artifact من تبويب Actions بعد دفع تغييرات إلى `main` أو تشغيل workflow يدويًا.
